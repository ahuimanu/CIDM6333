## ste_check lines declined, and why
The checker ran on prose extracted from each page (body text minus SVG, blockquotes, code; plus JS string literals of six words or more). Declined:
- Every "sentence over 25 words" in explanatory paragraphs and captions: the brief sets no ceiling there (rules 1 to 4 only). The long sentences carry lists of conditions (the five things that never count as authority; the four falsifiers; the six kinds of evidence), quotations, or a qualification whose split would lose scope. Long lines that are JavaScript code are extractor artifacts.
- "gerund/nominalized subjects": harness, session, description, observation, authorization, attention, embedding, decision, compaction are the stipulated nouns of these figures, not nominalizations standing in for verbs. "Every observation is data" is the deck's rule.
- "passives with no actor": "is appended"/"is added" cases were rewritten (above). Declined: "can be served from a prompt cache" (the provider is stated in the next clause), "cannot be scripted" (the deck's wording, and the agent is the path itself), "is validated... is retried or rejected" (Pydantic AI's machinery, described by what happens to the output), "were fixed when training ended" (the trainer is not the point), "is counted in tokens", "is deprecated in 2026-07-28" (the spec is the actor and is in the sentence), quotations.
- "noun clusters of 4+": nearly all are false positives on code identifiers, proper names, or words the heuristic reads as nouns ("own layout color roles", "current standards frontier models"). "critical" cases such as "server-side request forgery risk" are the standard's own term; left.
- Semicolon counts: left where noted above.
