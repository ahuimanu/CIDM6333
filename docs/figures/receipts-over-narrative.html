The black box · E11 slide 4 · Ch. 20.1

Four kinds of record

Each record answers a different question. A sortie needs at least three of the four.

RecordWhat it isQuestion it answersYour system this week
Trace and spansA tree of timed operations for one run: the agent invocation, each model call, each tool call, with attributes and a statusWhat happened, in what order, how long it took, what it costA span per model call and per tool call, written by your loop to a file
ReceiptA schema-validated record of a command's observed result: exit status, duration, git state, stdout tailDid the command run, on which commit, and what did it returnOne receipt per guardrail refusal and per gate run
LedgerThe append-only event log that is the runtime truth of the projectWhat was decided, attested, and closed, and by whomLedger events for the card, the Go, each attack, the verdict
TranscriptThe conversation text, including the model's statements about its own actionsWhat the model said. Evidence of nothing it claims to have doneKept local; never promoted to the flight log without a matching span

A span records that an operation happened. A receipt binds the observed result to a commit. A transcript is a claim until a span or a receipt agrees with it. The narrative in the figure is the transcript row.

E11 slide 6 · the black box is also an attack surface

What to log, and what never to log

Always

  • Operation name, model id, provider
  • Tool name, call id, status, error.type
  • Start, end, duration
  • Token counts and cost per call
  • Git commit and dirty flag
  • Which guardrail refused, and the rule id

Only by decision

  • Prompt and response text
  • Tool arguments and results
  • System instructions

Turn on per sortie, not by default. Record the decision in the ADR for this layer. Hash or truncate where the Chase needs only identity.

Never

  • API keys, tokens, passwords, cookies
  • Contents of .env or credential files
  • Personal data about any person, including you
  • Raw exports that carry any of the above

A canary string stands in for a secret in your tests. If the canary appears in a committed file, that is a leak. The deck's warning: an attacker who can make the agent print a secret wins twice if your logger then writes it to disk. The trace in the figure holds metadata only, and the metadata was enough to catch the false claim.

What the figure leaves out

  • The first five span lines and their token counts follow the deck's example span tree. The retrieval span, the third model call, all timings, the narrative text, and the cost figures are illustrative. Costs use the deck's opencode-go/glm-5.3-flash list prices ($0.15/M input, $0.50/M output, checked 09/24). On Big Pickle the model bill is $0.00.
  • The deck lists no separate span name for retrieval, so the figure draws retrieval as an execute_tool span for a search tool.
  • Fields such as start, end, cost, git commit, and the guardrail's rule id are the deck's “always log” list. They are your own fields, not names from the GenAI conventions.
  • The conventions also define metrics (gen_ai.client.operation.duration and token-usage histograms) and an evaluation event (gen_ai.evaluation.result). The figure draws spans only. The conventions have status Development, so names can still change.
  • The trace shows the model bill. The supervision cost does not appear in it. The deck's worked example puts one sortie at $0.19 of model cost against $37.50 of your attention.
