Three Drawers

Your harness has three places where something lasts beyond one session, and each has a different price. AGENTS.md is in the window on every turn. A skill costs one line every turn and its full text only when the model calls it. A memory record costs nothing until it scores above a threshold. A fact in the wrong drawer is paid for every turn, never found, or found too late.

Where this is tested

  • In class on 10/22: the exercise "One intent, three drawers." Each team files one intent three ways and measures the cost of each filing.
  • Sortie 7: the recall probe for AGENTS.md, the skill tool call under permission.skill ask, and the memory on/off runs with the record id cited.
  • E5 Sprint: the trust boundary. The retrieved block and the skill body are content; the model treats them as data, not instructions.
  • Final System: V&V must show the harness acts on the brief across many sessions, so a per-turn cost repeats per session.
