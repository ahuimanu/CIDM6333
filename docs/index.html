Exercises

In class · pairs · 40 minutes One Intent, Three Drawers AGENTS.md, a skill, and a memory store built side by side, then three probes that show which one the model used, and a planted record that contradicts the intent. In class · follow along · 60 minutes Steer the Middle E0 to E8 in your own repository: locate every file on the outer ring, make it fire, record the trace, then build a reviewer agent that cannot edit and put it to the test on a codec change.
