CIDM 6333 · Agentic Systems Design and Development

Figures

Interactive explainers for the course, one or more for each Evolution. Each one steps through a mechanism the lecture describes. Use Next and Back, the step dots, or the arrow keys, then try the interactive panels below each figure.

Figure 01 · E0 E1 E6 E10 Two Loops How a language model writes one token per pass inside the agent loop your harness runs, with a temperature sampler and a per-turn token cost chart. Figure 01b · after Vaswani et al. (2017) The 2017 Transformer Figure 1 of Attention Is All You Need redrawn and quoted step by step, with a decoder-only switch, live attention, positional encodings, and Tables 1 and 3. Figure 01c · E10 E6 E11 The Transformer's Evidence The paper's evidence as working charts: cost against BLEU, one-change ablations, the warmup schedule, the attention pictures, and parsing. Figure 02 · E1 The Loop That Halts The agent loop as a state machine with an exit for every halt condition, and a budget simulator that shows the spiral when the halt check is off. Figure 03 · E2 Who Owns the Loop The five workflow patterns and the agent as mechanisms, and a framework picker that shows who owns each part of the loop. Figure 04 · E3 The Gate Holds One tool call played through model, harness, permission gate, human, tool, and ledger, for read, write, destructive, malformed, and injected calls. Figure 05 · E4 N×M Becomes N+M Sliders redraw direct integrations beside MCP, with hosts, clients, servers, and the three server primitives. Figure 06 · E5 Trust Boundaries The five-step MCP authorization flow, the threat model as trust boundaries, and a live hash-pin check on a tool description. Figure 07 · E6 Window Budget The context window by who fills it, the per-turn budget record, a compaction simulator, and the 258K exhaustion. Figure 08 · E7 Memory Is a Claim Chunk, represent, store, score, inject: four questions against a five-record store with two retrievers, eviction, and a ledger. Figure 09 · E8 Plan, Do, Check Controller, worker, and reviewer as a state graph with typed results, replaying the deck's trace with a read-only or editing reviewer. Figure 10 · E9 Claim, Receipt, Verdict Who writes each record and which ones are evidence, the MAST failure matrix, and the ten-deep chain with and without receipts. Figure 11 · E10 One Run Is an Anecdote The delta gate from golden set to exit code, with a simulation of how often a gate that sees few runs gets it wrong. Figure 12 · E11 Receipts Over Narrative A span waterfall of one agent run where the trace catches a claim the agent's own account got wrong. Figure 13 · E12 Rolled Back The release path and the way back, a circuit-breaker simulator, and two ways to ship the same release.
