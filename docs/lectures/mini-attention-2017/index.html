03

The constraint: recurrence is a queue

  • Table 1 of the paper, redrawn; n is sequence length, d is the model width
  • Layer type · Complexity / layer · Sequential ops · Max path
  • Self-attention · O(n²·d) · O(1) · O(1)
  • Recurrent · O(n·d²) · O(n) · O(n)
  • Convolutional · O(k·n·d²) · O(1) · O(logₖ n)
  • Self-attention (restricted) · O(r·n·d) · O(1) · O(n/r)
  • What the authors faced
    Recurrence reads one token per step. Each step waits for the last; a sentence cannot spread across a GPU.
    The trade: all positions attend to each other at once. Sequential steps O(n) → O(1); compute per layer grows with n².
  • Self-attention is cheaper than recurrence "when the sequence length n is smaller than the representation dimensionality d, which is most often the case" (§4). In 2017, n was a sentence of about 30 tokens and d was 512.
  • O(n) → O(1)
    sequential steps per layer, recurrent vs. self-attention
  • In 2026, n is your context window, far past d. The n² term is the cost you budget in E6.
04

Figure 1, redrawn: two stacks and a loop

  • Layout, names, and color roles follow the paper; the dashed return arrow is ours (§3 says the model is auto-regressive)
  • Encoder (left)
    Reads the source sentence. Every position attends to every other, in both directions.
  • Decoder (right)
    Writes the translation one token per pass. Its first attention layer is masked: it can look back, never ahead.
  • The base model
    N = 6 layers per stack, d_model = 512, 8 heads, about 65M parameters, 12 hours on one machine with 8 P100 GPUs.
  • The loop
    "At each step the model is auto-regressive, consuming the previously generated symbols as additional input when generating the next" (§3).
05

Scaled dot-product attention: one line, three choices

  • §3.2.1 and §3.2.3; the grid is computed from random vectors and shows arithmetic only
  • Attention(Q, K, V) = softmax( QKᵀ / √d_k ) V
  • Q, K, V come from one place
    In self-attention "all of the keys, values and queries come from the same place." Each is a projection of the same input.
  • Divide by √d_k
    Large dot products push softmax into "regions where it has extremely small gradients." Scaling keeps the weights trainable.
  • Mask the future
    The decoder sets illegal connections to −∞ before softmax, so each position predicts only from earlier positions.
  • Rows are queries, columns are keys, each row sums to 1. The striped cells are the −∞ entries. Figure 01b lets you turn scaling off and raise d_k until each row collapses onto one key.
  • The mask is the one detail every chat model still uses unchanged.
06

Eight heads, and word order written in waves

  • Figure 2 (right) redrawn, and the sinusoidal positional encoding of §3.5
  • Multi-head: h = 8 heads, each of width d_k = d_v = 512 / 8 = 64. Total computation matches one full-width head. Table 3 row A: one head scores 0.9 BLEU worse than the best setting, and 32 heads also drop.
  • Position: attention alone ignores word order, so each position adds sine and cosine waves of different wavelengths. Table 3 row E: learned positions gave nearly identical results.
  • Heatmap rows: positions 0–99; columns: dimensions 0–127 of 512; blue −1, amber +1.

Evidence 2: one change against a fixed base

  • Table 3, English-to-German dev set (newstest2013); change in BLEU from the base model's 25.8
  • What the authors concluded (§6.2)
    "bigger models are better, and dropout is very helpful in avoiding over-fitting."
    "reducing the attention key size d_k hurts model quality."
  • Read it as an eval gate (E10)
    One variable per row. A fixed base. A dev set kept apart from the test set. Every row is a delta against the same baseline, which is the shape of your Sortie 10 gate.
  • Before you trust a row, ask what threshold you would have pre-registered. A 0.1 change is inside run-to-run noise.
09

The recipe the results depend on

  • Equation 3 (§5.3): warm up linearly, then decay with the inverse square root of the step
  • lrate = d_model⁻⁰·⁵ · min(step⁻⁰·⁵, step · warmup⁻¹·⁵)
  • The rest of the recipe
    Adam, β₁ = 0.9, β₂ = 0.98, ε = 10⁻⁹.
    Dropout 0.1 on sub-layers and embeddings.
    Label smoothing 0.1 "hurts perplexity, as the model learns to be more unsure, but improves accuracy and BLEU score."
    100,000 steps base, 300,000 big.
  • A result is the architecture plus its recipe. Change the recipe and the claim no longer holds as stated.
10

What chat models kept: the right-hand column

  • GPT (Radford et al., 2018) and its descendants drop the encoder and the encoder–decoder attention
  • Kept
    Token embeddings and position
    Masked self-attention
    Feed-forward and Add & Norm, stacked N times
    Linear and softmax over the vocabulary
  • Dropped or changed
    The encoder stack
    Encoder–decoder attention
    Beam search, in favor of sampling
    Post-norm: most later models normalize before each sub-layer
  • One sequence. The prompt and the reply become one stream of tokens. The model reads all of it and writes the next token, then the harness or the model's own loop appends that token and runs again.
  • Sampling replaced beam search, which is why the same prompt can give different answers (E10).
